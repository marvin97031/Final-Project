# User Stories - Smart Clinic Management System

## Doctor
- As a doctor, I want to log in securely so that I can manage my appointments.
- As a doctor, I want to view my daily and upcoming appointments so that I can prepare for patient consultations.
- As a doctor, I want to access a patient's medical history and details so that I can provide accurate diagnoses and prescribe medications.

## Patient
- As a patient, I want to register and log in securely so that I can manage my healthcare.
- As a patient, I want to search for doctors by specialty and view their available time slots so that I can book an appointment.
- As a patient, I want to view my upcoming appointments and cancel if necessary.
- As a patient, I want to view my prescriptions so that I know what medication to take.

## Admin
- As an admin, I want to log in securely so that I can manage the clinic's system.
- As an admin, I want to add new doctors to the system, providing their details and availability.
- As an admin, I want to view a list of all doctors so that I can manage staff records.
